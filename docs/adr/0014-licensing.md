# ADR-0014: License for our own code

**Status:** Accepted (owner 2026-09-07: "free, open source, let them do whatever they want")
**Date:** 2026-09-07
**Deciders:** project owner

## Context

Dependencies: stylo/cssparser/mozjs — MPL-2.0 (file-level copyleft); V8 — BSD-3; vello/wgpu/parley/html5ever/taffy — MIT/Apache; tiny-skia — BSD-3; Chromium `sync.proto`, CRX3 — BSD-3 (Chromium). The Rust ecosystem expects `MIT OR Apache-2.0`. Our own code must be compatible and leave the choice of model open (open source / open core / proprietary shell).

## Decision

- Our own code: **Apache-2.0 OR MIT** (dual) — maximally permissive, the Rust ecosystem standard; the recipient picks either. Apache's patent protection + MIT's simplicity.
- MPL-2.0 dependencies are used without modifying their files; our changes go through upstream PRs or a separate fork repository that publishes the modified files (an MPL requirement).
- `deny.toml` allowlist: MIT, Apache-2.0 (+LLVM-exception), BSD-2/3, ISC, Zlib, MPL-2.0, Unicode-3.0, CC0-1.0, OpenSSL (not used), BSL/SSPL/GPL/LGPL/AGPL — forbidden.
- SBOM (`cargo cyclonedx`) in release artifacts; `THIRD_PARTY_NOTICES` is generated by `cargo about`.

## Options Considered

| | Apache-2.0 OR MIT | MPL-2.0 | GPL-3.0 | Proprietary |
|---|---|---|---|---|
| Compatibility with deps | full | full | full (but one-way) | full if notices are honored |
| Community contribution | maximal | good | limited | none |
| Protection against "take it and close it" | none | file-level | strong | — |
| Commercial options later | yes | yes | hard | yes |

## Consequences

- Easier: contributors, reuse in other Rust projects.
- Harder: competitors can take the code; for a solo project this is not the main risk.
