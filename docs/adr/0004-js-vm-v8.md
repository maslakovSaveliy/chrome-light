# ADR-0004: JS/Wasm VM — V8 за трейтом `JsRuntime`

**Status:** Accepted (revisit at M4)
**Date:** 2026-09-07
**Deciders:** владелец проекта

## Context

JS VM — отдельный слой от движка. Собственный VM с оптимизирующим JIT — многолетняя программа (референс прямо запрещает включать его в MVP). Цель «поведение как у Chrome» для JS достигается только V8: те же баги, те же расширения ECMAScript, тот же Wasm. Crate `v8` (rusty_v8) stable с 129.0, версии = Chrome, prebuilt binaries, 152.2.0 на 2026-09-07. Альтернативы: `mozjs` 0.26 (SpiderMonkey, Servo), `boa` (чистый Rust, медленный, неполный), свой.

## Decision

V8 через crate `v8`, инкапсулирован в `cl-js` за трейтом `JsRuntime` (создание isolate/context, компиляция/выполнение, promise/job queue hooks, инспектор, snapshot, memory pressure API). Никакой другой crate не импортирует `v8::` напрямую. Один isolate на renderer main thread, context на `Window`; workers — isolate на поток. Обновление V8 — в течение 7 дней после релиза Chrome (2-недельный ритм). JIT-less режим (`--jitless`) — обязательная опция (фоновые вкладки, «secure mode»).

## Options Considered

| | V8 (`v8`) | SpiderMonkey (`mozjs`) | Boa | Свой |
|---|---|---|---|---|
| Chrome-семантика | да | почти | нет | нет |
| Память idle isolate | ~2–5 МБ + heap; снижается snapshot/`--jitless` | сопоставимо | мала | — |
| Wasm | да | да | нет | нет |
| Инспектор (CDP Debugger/Runtime) | встроен → DevTools бесплатно | есть, другой протокол | нет | нет |
| Сборка | prebuilt, C++ в бинарнике (~30–40 МБ) | сложная, Python/Mach | cargo | — |
| Риск | C++ баги, размер | то же + сложнее сборка | несовместимость, скорость | годы |

## Trade-off Analysis

V8 даёт Chrome-паритет JS и DevTools-инспектор ценой C++ в TCB и размера бинарника. Трейт `JsRuntime` оставляет путь к Rust VM (Boa или свой) для конкретных режимов (например, embedded/low-memory), но не для v1.

## Consequences

- Легче: JS-совместимость, Wasm, Debugger/Profiler через V8 Inspector.
- Труднее: V8 тянет C++ toolchain для сборки из исходников (используем prebuilt с checksum); memory-safety V8-багов наследуем → sandbox критичен; размер.
- Пересмотреть на M4: измерить долю памяти V8 в бюджете; если >40% renderer-а на типичной странице — исследовать snapshot/lazy-isolate/Boa для фоновых вкладок.
